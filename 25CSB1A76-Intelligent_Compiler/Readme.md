🖥️ How to Use the Web IDE
Once the web page opens, you will see a full VS Code-themed editor. Here is what you can do:
Pick an Example or Write Your Own Code:
On the left sidebar (Project Files), click any file inside `examples/` (like `week12_benchmark/missingsemicolon.c` or `week12_phase4/autofix_gets.c`).
Or simply type/paste your own broken C code into the editor.
Choose Your Mode (Autocorrect Toggle):
Autocorrect: ON (Top bar switch): The compiler will automatically repair your code directly inside the editor when you run it.
Autocorrect: OFF: The editor will not change your code automatically. Instead, it generates Suggestion Cards on the right side with a diff preview, letting you inspect each fix and click Apply Suggestion manually.
Click `▶ Run Current File`:
Watch the real-time progress bar.
View the Confidence Dashboard (showing how reliable the fix is, e.g. 95%).
View the Error Dependency Graph (shows if one mistake caused other phantom errors).
Read the AI Error Explanations (teaching you what was wrong and how to write clean C code).
Test the Security Auto-Fixer:
Load a file that uses dangerous functions like `gets(buf);` or `strcpy(dst, src);`.
Click Run Current File.
Notice how it automatically upgrades them to safe alternatives like `fgets(buf, sizeof(buf), stdin);` and `strncpy(dst, src, sizeof(dst));`.
Test the AAI Shield (Attack Simulator):
On the right panel, scroll down to AAI Security Shield.
Pick an attack scenario (e.g. `Prompt Injection (Comment Jailbreak)`).
Click Simulate Attack.
Watch how the shield intercepts adversarial comments (e.g., attempts to bypass security checks) and logs them in the audit table.
Change Themes:
Click the 🌙 Dark Mode / ☀️ Light Mode button at the top to toggle between VS Code Dark and Light themes.

📁 Simple Folder Guide (What Does Each Folder Do?)
Folder Name	Simple Plain English Explanation
`app.py`	The main file that starts the Flask web server and connects the frontend to the compiler.
`compiler/`	The "brain" of the project. Contains all the logic for fixing missing brackets, fixing typos, repairing syntax, checking types, fixing security flaws, and calculating energy usage.
`gui/`	The frontend website files. Contains `templates/index.html` (the Monaco editor web page), `static/app.js` (button clicks and events), and `static/style.css` (VS Code styling).
`grammar/`	Contains `SimpleC.g4`, the official ANTLR4 language rules defining what valid C code looks like.
`generated/`	Code auto-generated by ANTLR4 (`SimpleCLexer.py`, `SimpleCParser.py`) that turns raw C text into tokens and syntax trees.
`examples/`	Pre-made C programs containing different errors (typos, missing semicolons, missing brackets, buffer overflows) for quick testing.
`tests/`	Automated test files that check that all features and security shields work properly.
`ml/`	Machine learning scripts used to train and run the CodeT5 AI model.
`models/`	Saved weights and LoRA adapters for the CodeT5 AI model.
`data/`	Datasets used for testing attacks (`aai_benchmark_dataset.json`) and training error-repair pairs.
`tools/` & `scripts/`	Helper scripts used to verify datasets, check for duplicates, and generate sample code.

❓ Common Troubleshooting & FAQ
Issue: `'python' is not recognized as an internal or external command`
Fix: Install Python from python.org and make sure to check the box "Add Python to PATH" during installation.
Issue: `Address already in use` or Port 5000 is busy
Fix: Another program (or a previous run of `app.py`) is using port 5000. Close the previous terminal or restart your computer, then run `python app.py` again.
Issue: Monaco editor is blank or not loading
Fix: The Monaco editor is loaded via CDN (`cdnjs.cloudflare.com`). Make sure your computer is connected to the internet the first time you load the page.
